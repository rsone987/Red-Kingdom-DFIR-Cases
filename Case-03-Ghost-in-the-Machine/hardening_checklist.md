# BIOS/UEFI Hardening Checklist — The Red Kingdom Standard

- [ ] BIOS/UEFI administrator password set
- [ ] Boot from USB/CD disabled
- [ ] Secure Boot enabled
- [ ] Boot order pinned to the internal drive only (`efibootmgr -o <internal-boot-id>`)
- [ ] Firmware update policy documented and scheduled
- [ ] Badge access logs cross-checked against HR shift/leave schedule on every physical-access incident
